# Process Terminating Messages — Interface

This is a front-end demonstration interface for the Operating Systems project
"Process Terminating Messages".

## Included modules
1. Process Creation
2. Process Execution
3. Process Monitoring
4. Process Termination
5. Signal Handling
6. Termination Status
7. Termination Messages
8. Testing & Error Identification

## Run
Open `index.html` in a web browser.

For the actual Linux/C implementation, connect the UI actions to your
C/C++ program using the project's Linux system calls such as fork(),
wait()/waitpid(), exit(), and kill().
