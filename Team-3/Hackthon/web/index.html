System Architecture

POSIX Mechanics & Process Lifecycle

A breakdown of the low-level operating system concepts, kernel system calls, and concurrency safety guarantees powering the supervisor.

1. Safe Spawning Engine

Uses fork() to replicate the process image and execvp() in the child to replace memory with the target binary. Avoids unsafe system() shells, preventing shell injection and preserving direct PID lineage.

fork() execvp() _exit(127)

2. Intelligent Exit Discrimination

Differentiates normal task exits (WIFEXITED && status == 0) from failures (WEXITSTATUS != 0) and fatal signal crashes (WIFSIGNALED && WTERMSIG) via bitmask status decoding.

waitpid(WNOHANG) WIFEXITED WTERMSIG

3. Async-Signal Safety

Signal handlers registered via sigaction() only mutate a volatile sig_atomic_t flag. The supervisor politely sends SIGTERM, waits, and escalates to SIGKILL if unresponsive.

sigaction() sig_atomic_t kill()

4. Zero-Zombie Guarantee

A zombie process (Z state) consumes kernel PID slots. The watchdog continuously reaps terminated children via waitpid() and performs a sweep during shutdown, ensuring 100% clean process tables.

Command Options

Generated Shell Command
wsl ./bin/watchdog --max-restarts 3 --restart-delay 2 --interval 1 --log logs/watchdog.log -- ./bin/crash_worker --segfault --delay 2

Option Breakdown:

  • --max-restarts 3: Halts supervisor after 3 consecutive failures to avoid infinite crash loops.
  • --restart-delay 2: Waits 2 seconds between restart attempts for graceful cool-off.
  • --interval 1: Queries Linux /proc health status every 1 second.
  • --log logs/watchdog.log: Writes dual-stream ISO timestamped audit logs to file.
  • --: POSIX argument separator marking start of the target command.
